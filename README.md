# መልካም አዲስ ዓመት 2019 ዓ.ም 🌼

Interactive Ethiopian New Year (2019) greeting page with:

- Personalized name + gift box animation
- Canvas fireworks, falling Adey Abeba (daisies), night sky & hills
- Ambient music + sound effects
- Full mobile-first experience (safe areas, haptic feedback, performance-tuned particles)
- Shareable link with name pre-filled

## Live

Open the site after enabling GitHub Pages (Settings → Pages → Deploy from branch `root`).

Or visit: `https://menelik2.github.io/NewYear/` (once Pages is active).

## Usage

1. Enter a name (Amharic or English)
2. Open the gift
3. Enjoy the greeting + fireworks
4. Tap empty space to launch more fireworks
5. Share with friends

## Tech

Pure HTML / CSS / JS — no build step, no dependencies.

Developed with ❤️ for Ethiopian New Year.
